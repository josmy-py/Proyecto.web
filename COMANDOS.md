# Comandos

## Requisitos
- Python 3.10+
- Camara web (solo si vas a jugar en modo Camara) o un mando/joystick conectado (solo si vas a jugar en modo Mando)

## Instalar dependencias
```bash
pip install -r requirements.txt
```

## Ejecutar el juego
```bash
python main.py
```

En Windows tambien se puede ejecutar con doble clic en `run.bat`.
